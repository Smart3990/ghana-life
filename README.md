# Ghana Life (working title)

A free browser life game set in Ghana. The full plan is in `docs/MASTER_PLAN.md` (text copy) and `docs/Ghana_Life_Master_Plan.pdf` (original).

## Run the web app on your computer

```
cd apps/web
npm install
npm run dev
```

Open the address it prints. To try it on your phone, use the "Network" address while the phone is on the same Wi-Fi.

## Put it online (Cloudflare Pages)

```
cd apps/web
npx wrangler login     # once, opens your browser
npm run deploy
```
